        )
    do
        if [[ ${network} != 'podman' ]]

            podman network rm ${network}
        fi
    done

    The pinned image resolves from KNOWN_DIGESTS and is cached in

    rebuild and unpinned tags such as alpine:3 still cannot be resolved.

Issues and observations
* The session read endpoints are anonymous.  GET /sessions/{uuid} and both
  connector URLs return HTTP 200 without credentials, while POST /requests
  and POST /admin/identities require auth (401).  Container stdout and stderr
  are therefore readable by anything that can reach the broker port.
* The image digest probe is still ineffective (item 7).  The demo avoids this
  by pinning alpine:3.23, but the docker helper-image default in
  application.yaml is alpine:3, which cannot be resolved.
* There is no DELETE for /admin/identities, and identities and components have
  a circular foreign key, so a temporary identity can only be removed with
  direct database surgery.
* The broker logs directory /var/calycopis/log is empty (no broker.log is
  written), which underlines that log parsing is not a viable result path and
  the session connectors are the only option.  No broker.log / LOG_PATHS
  references remain in demo/bin.
