# Retrofitting the branch.
#[root@lithosia-dsh-pod]

    The two commits already on this branch had no Signed-off-by trailer, so
    the DCO requirement in CONTRIBUTING.md was unmet for them. Signed them
    off with:

        git rebase --signoff --autostash main

    The branch had unstaged note edits in the working tree, hence --autostash.

    That rewrote both commits, so the hashes changed:

        42c92d82 -> b3b8bd75   Update AGENTS.md for mount-dependent container paths
        07681278 -> f5e9a3c3   Split the container deployment guide out of AGENTS.md

    Both now carry `Signed-off-by: Dave Morris <dave.morris@manchester.ac.uk>`,
    and the author is still the human because they predate this arrangement. No
    tracked file cited the old hashes, so nothing else needed updating.

    Commits made from here on are authored by the agent and signed off by the
    human, so this is the last rebase of this kind the branch should need.
